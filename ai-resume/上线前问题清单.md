> 分析日期：2026/05/30

## 一、安全问题（严重程度：高）

### 问题 1：`.env` 文件已被 git 跟踪并提交 `P0` ✅ 已修复

- **文件路径**：`ai-resume/.env`
- **内容**：`VITE_API_BASE_URL=http://localhost:3000/api/v1` 和 `VITE_DEFAULT_AVATAR=http://localhost:3000`
- **现状**：`.gitignore` 中没有排除 `.env` 文件，只排除了 `*.local` 模式的文件
- **风险**：一旦在 `.env` 中添加真实的 API key 或密钥，会自动被提交到仓库
- **修复措施**：
  - 在 `.gitignore` 中添加 `.env` 和 `.env.*` 规则（排除 `.env.example`）
  - 从 git 跟踪中移除 `.env` 文件（`git rm --cached .env`）
  - 创建 `.env.example` 供团队参考

### 问题 2：测试文件中硬编码了真实凭据 `P0` ✅ 已修复

- **文件路径**：
  - `ai-resume/tests/specs/auth-flows.spec.ts` 第 18-19 行
  - `ai-resume/tests/mocks/api.ts` 第 48 行
- **内容**：真实个人邮箱和密码被硬编码在测试文件中
- **风险**：随代码仓库暴露个人账号信息
- **修复措施**：改为从环境变量 `TEST_USER_EMAIL` / `TEST_USER_PASSWORD` 读取，默认值使用虚构凭据

### 问题 3：多个 `v-html` 指令存在 XSS 风险 `P1` ✅ 已修复

- **涉及文件（共 8 处）**：
  - `ai-resume/src/views/editor/components/preview/CampusExperienceSection.vue`
  - `ai-resume/src/views/editor/components/preview/CertificatesSection.vue`
  - `ai-resume/src/views/editor/components/preview/EducationBackgroundSection.vue`
  - `ai-resume/src/views/editor/components/preview/InternshipExperienceSection.vue`
  - `ai-resume/src/views/editor/components/preview/ProjectExperienceSection.vue`
  - `ai-resume/src/views/editor/components/preview/SelfEvaluationSection.vue`
  - `ai-resume/src/views/editor/components/preview/SkillsSection.vue`
  - `ai-resume/src/views/editor/components/preview/WorkExperienceSection.vue`
- **风险**：用户输入包含恶意脚本时，`v-html` 会直接渲染执行，造成存储型 XSS 攻击
- **修复措施**：
  - 安装 DOMPurify 库
  - 创建 `v-safe-html` 自定义指令（`src/directives/safeHtml.ts`）
  - 全局注册指令并在所有 8 处替换 `v-html` 为 `v-safe-html`
  - ESLint `vue/no-v-html` 规则提升为 `error`

### 问题 4：OAuth state 参数的安全性 `P2`

- **文件路径**：`ai-resume/src/views/auth/LoginPage.vue` 第 156 行
- **现状**：OAuth 回调页面需要验证 state 参数以防 CSRF，需确认回调页面确实做了比对验证
- **建议**：检查回调页面的 state 验证逻辑

## 五、错误处理问题

### 问题 16：部分 API 调用缺少错误处理 `P2`

- **涉及文件**：
  - `ai-resume/src/views/template/TemplateDetailsPage.vue` -- 多个函数的 `try...finally` 块中没有 `catch` 分支
  - `ai-resume/src/views/user/GenerationRecords.vue` 第 83-96 行 -- `fetchRecords` 函数缺少 `catch`

### 问题 17：Axios 请求超时设置过长 `P2`

- **文件路径**：`ai-resume/src/http/request.ts` 第 7 行
- **现状**：超时时间为 100 秒（约 1.67 分钟）
- **建议**：根据接口类型设置不同的超时时间，普通接口 15-30 秒，AI 生成等长耗时接口可单独设置

### 问题 18：AI 分析按钮禁用逻辑反转 `P0` ✅ 已修复

- **文件路径**：`ai-resume/src/views/editor/components/AiAnalysisDrawer.vue` 第 63-65 行

## 总体评估

项目核心框架和代码组织质量较好，使用了现代的 Vue 3 + TypeScript + Vite 技术栈，代码规范工具链（ESLint + Prettier）配置完善，路由守卫、状态管理、HTTP 请求拦截器等基础设施搭建合理。
