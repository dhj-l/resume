# AI 简历管理系统 - 待办事项清单

## 1. 项目现状概述

AI 简历管理系统是一个基于 Vue 3 + TypeScript + Ant Design Vue 开发的在线简历制作平台，目前已实现了以下核心功能：

- **用户管理**：用户注册、登录、个人信息管理、密码修改
- **简历管理**：简历创建、编辑、删除、复制、PDF 下载
- **模板管理**：模板列表查询、模板详情查看、创建模板
- **上传模块**：图片上传、简历文件解析
- **AI 模块**：AI 简历生成

项目采用前后端分离架构，前端使用 Vite 构建，后端基于 NestJS + MongoDB 实现。当前项目已完成基础框架搭建和核心功能的初步实现，但仍有部分 API 接口、功能组件和性能优化工作尚未完成。

## 3. 优先级划分

### 3.1 高优先级（影响核心功能使用）
1. 模板模块：使用模板创建简历接口及前端功能
2. 简历模块：简历预览接口及前端功能
3. 用户模块：退出登录功能
4. 模板模块：更新模板接口及前端功能
5. 模板模块：删除模板接口及前端功能

### 3.2 中优先级（增强用户体验）
1. 简历模块：搜索简历接口及前端功能
2. 简历模块：导出/导入简历 JSON 接口及前端功能
3. 模板模块：按分类获取模板接口及前端功能
4. 模板模块：获取热门模板接口及前端功能
5. 用户模块：管理员相关功能（获取所有用户、获取单个用户、更新用户信息、删除用户）

### 3.3 低优先级（非核心扩展功能）
1. 模板模块：收藏/取消收藏模板接口及前端功能
2. 模板模块：获取用户收藏的模板接口及前端功能
3. Share 模块：简历分享功能
4. History 模块：简历历史记录功能
